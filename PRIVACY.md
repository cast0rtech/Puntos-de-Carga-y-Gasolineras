# Política de Privacidad

**Última actualización:** 12 de septiembre de 2026

**Castor Tech** (en adelante, "nosotros", "nuestro" o "el Desarrollador") ha creado la aplicación móvil de búsqueda de estaciones de recarga eléctrica y gasolineras (en adelante, "la Aplicación") como una aplicación de uso gratuito. Este SERVICIO es proporcionado por Castor Tech sin costo alguno y está diseñado para utilizarse tal cual.

Esta página se utiliza para informar a los usuarios sobre nuestras políticas con respecto a la recopilación, el uso y la divulgación de Información Personal en caso de que alguien decida utilizar nuestro Servicio.

## 1. Recopilación y Uso de Datos Personales

Queremos ser completamente transparentes con nuestros usuarios: **nuestra Aplicación NO recopila, NO almacena y NO comparte ningún tipo de dato personal.**

Al utilizar nuestra Aplicación, no se le solicitará que cree una cuenta, ni que proporcione su nombre, dirección de correo electrónico, número de teléfono o cualquier otra información de identificación personal. Castor Tech no dispone de servidores propios para almacenar datos de los usuarios, métricas de uso ni historiales de búsqueda.

## 2. Peticiones de Red y APIs de Terceros

Para proporcionar la información sobre la ubicación de las estaciones de servicio y puntos de recarga, la Aplicación debe conectarse a través de Internet a bases de datos públicas. Esta Aplicación utiliza específicamente los siguientes servicios de terceros:

*   **Open Charge Map API:** Para la obtención de datos de estaciones de recarga de vehículos eléctricos.
*   **OpenStreetMap (Overpass API):** Para la obtención de datos de gasolineras y estaciones de servicio convencionales.

**Es importante destacar que todas las consultas y peticiones de red hacia estas APIs se realizan directamente desde su dispositivo móvil.** 

Castor Tech no actúa como intermediario en estas peticiones. Al realizar estas conexiones directas, su dispositivo está sujeto a las políticas de privacidad de estos proveedores externos, quienes podrían registrar información técnica básica y anónima inherente a cualquier conexión web (como su dirección IP en el momento de la consulta). Le recomendamos consultar las políticas de privacidad de Open Charge Map y OpenStreetMap para más detalles.

## 3. Datos de Ubicación

Si en el futuro la Aplicación solicitase permiso para acceder a la ubicación de su dispositivo (GPS) con el fin de mostrar estaciones cercanas, estos datos se procesarían **exclusivamente de forma local** en su propio dispositivo. En ningún momento Castor Tech transmitirá, guardará o registrará su ubicación geográfica.

## 4. Enlaces a Otros Sitios

La Aplicación puede contener enlaces o referencias a otros sitios web o servicios (por ejemplo, al mostrar la página web del operador de una estación de carga). Si hace clic en un enlace de un tercero, será dirigido a ese sitio. Tenga en cuenta que estos sitios externos no son operados por nosotros. Por lo tanto, le recomendamos encarecidamente que revise la Política de Privacidad de estos sitios web. No tenemos control ni asumimos ninguna responsabilidad por el contenido, las políticas de privacidad o las prácticas de sitios o servicios de terceros.

## 5. Cambios en Esta Política de Privacidad

Es posible que actualicemos nuestra Política de Privacidad de vez en cuando. Por lo tanto, le recomendamos que revise esta página periódicamente para ver si hay cambios. Le notificaremos cualquier cambio publicando la nueva Política de Privacidad en esta misma página. Estos cambios entran en vigor inmediatamente después de su publicación.
